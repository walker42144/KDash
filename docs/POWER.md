# r16 电源与恢复

KPW3实机证据：event0 / max77696-onkey / KEY_POWER116，仅观察不EVIOCGRAB；触控event1独占，二者不同设备。短按释放<2秒为切换，长按/重复/丢帧不作为短按。物理事件后3秒抑制对应LIPC回声，其余goingToScreenSaver/outOfScreenSaver仍处理。readyToSuspend/wakeupFromSuspend记录日志，其固件实际组合仍需实机核对。

运行时重置 touchScreenSaverTimeout 1，并将preventScreenSaver释放以保留物理休眠能力；此属性的固件行为不能只凭模拟测试证明。每60秒检查，偶发失败5秒后重试，累计3次失败退出恢复。手动息屏前换上给定壁纸并GC16清理，再请求系统状态协调；后台控制器防止过期请求反向切换。唤醒只重绘一次，不额外恢复旧画面再全刷。

息屏阻止新自动同步与绘制；已发出的HTTP/完成写操作可收尾，避免误以为未提交。主循环继续观察按键，实际suspend、Wi-Fi和前光由系统管理，不能根据“没有刷新”推定已经深度休眠。

单个本地命令有8秒超时；失败屏幕清理只重试一次。恢复保留原版快照、两次GC16、两次sleep2及精确PID身份检查。恢复最多3次，卡住的恢复进程看护60秒；失败保留证据、不无限闪屏。

session-limit=0取消首测三分钟期限。只有进程死亡等明确异常触发看护；并非运行三分钟自动退出。主循环仍活着但挂住时，若书库可操作，Recovery会跳过最近30秒有心跳的健康owner，允许处理无心跳的卡住会话；完全不可操作时须按设备故障恢复方式处理。
