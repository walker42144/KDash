# 版本演进与历史源码

这里记录项目从早期设备诊断发展到 R19 的主要变化。历史标签是根据本地留存源码制作的**隐私清理快照**：个人名称、事件、精确位置、私人壁纸和敏感配置已替换或移除，因而不与当时设备中的程序逐字节一致。它们用于学习和对比，**不是经过验证的回退安装包**；请使用当前 [安装和回退教程](INSTALL.md)。

## 更早的阶段

早期本地备份主要记录每次替换前的少量文件，并不都是完整版本。经过隐私清理的 [R2—R12 更新前代码片段](../history/early-fragments/) 仅供研究，不可单独安装或回退。

- **R2—R3**：从只读设备诊断出发，修正书库启动、触控退出和原版界面恢复；首次试机的自动退出不再作为常规使用限制。
- **R4—R5**：将时钟、倒计时、待办和天气整合到同屏分区；建立统一刷新基准及周期协调，减少错开刷新。
- **R6—R7**：调整页眉、退出按钮、字体及视觉对齐。
- **R8—R9**：完善滴答任务勾选、子任务、优先级与显示开关，并收敛到今日任务。
- **R10—R12**：逐步改进电源键休眠、屏保、原版界面恢复、电池信息、天气展示、日出日落与手动刷新。R12 增加天气图表、昼夜条及刷新时刻对齐。

此列表只总结现有资料能支持的变化，不代表每一步都完成了所有设备或第三方服务的验证。早期源文件不完整的地方，仓库不会虚构完整版本。
