# 故障排查

- **书库没有入口**：确认设备已越狱、固件支持原版 Scriptlet，并确认三个 `.sh` 文件位于 USB 根目录的 `documents/`。不要假定所有 Kindle 都支持。
- **打开后等待或无法进入**：先等待原版界面完成恢复，避免反复点击；可运行书库里的 `KDash Candidate Diagnostics`，再检查 `kdash-candidate/logs/`。
- **退出后原版界面异常**：等待恢复完成；需要时从书库运行 `KDash Candidate Recovery`，再等待至少 45 秒。先备份日志和程序，勿直接改系统文件。
- **日期、日出日落不对**：检查设备时间、时区、事件日期和所填经纬度；天气和太阳计算位置需与实际地区一致。
- **天气或待办不更新**：核对模块是否启用、网络、服务授权、密钥及城市配置。公开问题前先清理日志中的任务、账号和密钥。
- **配置保存中断**：保持 USB 连接，在电脑工具中使用“恢复未完成保存”，再重新读取；不要直接删除 pending 文件掩盖问题。

完整安装与回退见 [INSTALL.md](INSTALL.md)。
