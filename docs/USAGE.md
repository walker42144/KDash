# 使用与配置

## 屏幕与操作

首页分为时钟与事件倒计时、待办、天气等区域。右上角刷新会请求即时刷新；退出返回 Kindle 界面。待办支持分页和完成操作；写入会影响你的滴答清单，请先用测试任务确认。短按设备电源键进入屏保，再次短按返回；空白壁纸是公开包的默认示例。

## 电脑配置工具

Windows 安装 Python 后可运行 `python pc_tool/configurator.py`；也可按 [构建指南](BUILD.md) 制作 EXE。连接 Kindle，选择其 `kdash-candidate/config.json`；读取不会写入，确认表单后才点击保存。不要把 `secrets.json` 或配置备份上传。

- **事件**：设置名称和日期（可选时刻）；到期显示依设备时间与时区计算。默认日期仅作示例。
- **滴答清单**：勾选“显示”表示启用；按工具引导授权并选择需要的清单。查看与完成任务的可用性取决于令牌和接口权限；完成操作会写回服务端。没有授权时不应当作真实空列表。
- **天气**：启用后设置高德 Web 服务 API Key 和城市 adcode；经纬度用于日出日落计算，必须自行设置为实际位置。其他供应商或新规则以其官方文档为准。
- **刷新**：显示刷新为基准；滴答、天气周期选择基准的整数倍，例如 1/15/45 分钟。初始十分钟整点校准，网络数据在统一显示时隙合并；手动刷新除外。息屏期间停止绘制，唤醒恢复。

配置保存采用事务恢复文件；若提示上次保存未完成，在工具内执行恢复，再重新读取。用户文件和授权信息属于私人数据，公开分享日志或截图前请自行检查。
